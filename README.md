# 🌿 EcoBazaar – AI-Powered Sustainable E-Commerce Platform

🌎 **EcoBazaar** is a full-stack, sustainability-focused e-commerce web application developed to encourage environmentally responsible shopping by connecting consumers with eco-friendly products through an intuitive, secure, and user-friendly digital marketplace. The platform aims to bridge the gap between sustainable brands and conscious consumers by making it easier to discover, explore, and purchase environmentally friendly products.

Built using **Spring Boot for backend development** and **Angular for frontend development**, EcoBazaar follows a scalable, modular, and secure architecture that supports three distinct user roles: **Admin, Seller, and Customer**. Each role is provided with dedicated functionalities and personalized dashboards to streamline platform management, product administration, and the overall shopping experience.

The application incorporates essential full-stack development concepts, including **JWT-based authentication and authorization, role-based access control, RESTful API integration, database management, and responsive user interface development**. It also focuses on enhancing the shopping experience through **AI-assisted eco-friendly product recommendations and intelligent product insights**, helping customers make more informed and sustainable purchasing decisions.

EcoBazaar provides a comprehensive set of features, including product discovery, product listing and management, inventory handling, user account management, and administrative controls. Sellers can manage their product listings, while administrators oversee platform activities and maintain smooth operations. Customers can browse sustainable products through an engaging interface designed to simplify product exploration and purchasing.

Additionally, the platform incorporates **dynamic UI theming, reusable Angular components, structured backend services, and seamless frontend-backend communication** to deliver a consistent and accessible user experience.

Overall, EcoBazaar demonstrates the practical application of modern web development technologies, secure authentication mechanisms, API-driven architecture, and sustainability-oriented digital solutions. The project highlights how technology can be leveraged to build scalable e-commerce applications while promoting environmentally conscious consumer behavior.
